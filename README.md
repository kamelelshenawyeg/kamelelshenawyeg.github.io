# Kamel Elshenawy | Portfolio

An editorial marketing portfolio with six case studies, campaign evidence, an About page, and contact details.

This is a static website. Serve the repository root with GitHub Pages. No installation or build step is required.

The front page is `index.html`. Navigation uses relative HTML links. Shared styles and the image viewer are in the bundled CSS and JavaScript files. Photos are local JPEGs.

Instrument Serif and Newsreader are included locally under the SIL Open Font License. Their license notices are included as text files in this repository.
